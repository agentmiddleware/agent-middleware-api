# Code of Conduct

## The short version

Be decent. Assume good faith. Keep criticism technical.

## What is expected

- Engage with the argument, not the person making it.
- Accept that "no" is a legitimate answer, particularly about scope. This
  project's boundary is narrow on purpose (see [`WEDGE.md`](WEDGE.md)), and a
  rejected feature is not a rejected contributor.
- Be willing to be wrong in public. Correcting a claim quickly is valued here
  more than being right the first time — the whole project is built around
  documenting what it cannot do.
- Respect that maintainer time is the scarcest resource. Small, well-described
  changes are a courtesy; large unexplained ones are a cost.

## What is not acceptable

- Harassment, personal attacks, or demeaning comments about anyone.
- Discrimination or derogatory remarks based on any personal characteristic.
- Publishing others' private information without explicit permission.
- Sustained disruption of discussions or deliberately derailing threads.
- Disclosing a security vulnerability publicly before the process in
  [`SECURITY.md`](SECURITY.md) has been followed. This one is both a conduct
  issue and a safety issue.

## Scope

This applies in every project space — issues, pull requests, discussions,
commit messages, and code review — and when representing the project elsewhere.

## Enforcement

Report concerns by opening a private security advisory (the same private
channel described in [`SECURITY.md`](SECURITY.md)) rather than a public issue.

The maintainer investigates and may warn, remove content, or block an account,
depending on severity. Reports are handled discreetly.

Be aware of a structural limitation, stated plainly because
[`GOVERNANCE.md`](GOVERNANCE.md) is honest about the rest of it: this project
has a single maintainer, so there is currently no appeal body and no
independent review of an enforcement decision. If the complaint is about the
maintainer, escalation options are limited to GitHub's own reporting
mechanisms. A second maintainer would fix this, among other things.

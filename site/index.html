00 / Operational problem

Agent intent is not authority—or evidence.

An agent can be correct and still exceed its mandate, retry an expensive call, or leave an operator unable to prove what ran. The gateway sits between the agent and one tool, and becomes the only path to that tool once you close the tool's other routes.

The result is inspectable before, during, and after execution without asking you to replace your agent framework.

  1. Before Bound the authority

    Tool, wallet, budget, expiry, and operator-defined scope.

  2. During Charge the call once

    The same accepted request key cannot become a second debit.

  3. After Return portable proof

    A signed receipt links the governed call to auditable evidence.

01 / Governed path

One control loop from intent to evidence.

Start with the smallest action where permission, cost, or audit evidence matters.

  1. 01Discover

    The agent reads the manifest: which tools exist and what each call costs.

  2. 02Authenticate

    The caller presents an operator-issued API key. There is no self-serve mint.

  3. 03Authorize

    A scoped permit binds the call to one tool, one wallet, a budget, and an expiry.

  4. 04Invoke

    With the tool reachable only through the gateway, an out-of-scope call is denied here.

  5. 05Meter

    The call is debited from the scoped wallet, once. The same key never debits twice.

  6. 06Receipt

    The terminal outcome is signed with Ed25519 and returned to the caller.

  7. 07Audit

    Wallet events are chained, so a later edit to the record is detectable.

  8. 08Govern

    Operators change scope, budget, and expiry from the control plane, not the agent.

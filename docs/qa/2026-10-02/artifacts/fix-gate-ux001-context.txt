1: /* ==========================================================================
2:    Agent Middleware API — "ledger night" design system
3:    Ground: deep navy ink, the colour of a ledger's cloth binding. Light
4:    surfaces are reserved for paper artifacts (the pilot ticket and the live
5:    receipt) — a receipt has to read as a document, not as a panel. Gold marks
6:    authority (the seal, the primary action); green is spent only on
7:    verification status; cyan and magenta are the arcade's trim and never
8:    carry meaning on a page.
9:
10:    Type is a three-role system: a serif display face for the headlines,
11:    because this product's promise is a signed document; a workhorse sans for
12:    card titles and controls; a mono for everything that is data — kickers,
13:    badges, receipt rows, code.
14:
15:    This system replaced the full arcade-cabinet treatment. The 8-bit idea was
16:    fun, and it survives in exactly two places: the footer's PRESS START
17:    control and the waiting room it opens (/arcade.css). Everything the buyer
18:    reads is set in a sans and a mono, on hairlines and soft corners, with no
19:    scanlines, no hard-offset shadows, and no pixel upscaling.
20:    ========================================================================== */

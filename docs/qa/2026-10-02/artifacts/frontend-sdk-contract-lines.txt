258: [docs/partner-first-tool-runbook.md](docs/partner-first-tool-runbook.md).

260: ### Python SDK
261: 
262: The typed `AgentMiddlewareClient` covers discovery, permits, governed
263: invocation, receipt verification, and evidence retrieval, and surfaces
264: idempotency conflicts and delivery uncertainty as explicit errors. CI builds
265: wheels and sdists on Python 3.10–3.12 and attaches them to `python-sdk-v*`
266: releases. **It is not published to PyPI, and there is no TypeScript package** —
267: install from this repository:
268: 
269: ```bash
270: python -m pip install -e './b2a_sdk[dev]'
271: ```
272: 
273: Offline verification is deliberately dependency-minimal: `b2a-verify-receipt`
274: checks a signed receipt against a published key set with only `cryptography`
275: installed. See [b2a_sdk/README.md](b2a_sdk/README.md).
